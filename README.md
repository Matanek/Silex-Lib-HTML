# HTML for Silex

`HTML` builds, parses, selects, transforms, and serializes HTML documents. It
escapes text and attributes by default and provides a bounded CSS selector API
for predictable document transformations.

```text
silex install HTML
```

- [English documentation](Docs/EN/README.md)
